## About Me

I'm a Java Full Stack Engineer based in Pune, India, working across the stack from Spring Boot backends to React frontends, with the infrastructure to deploy both reliably. I completed my B.Tech in Computer Science at DY Patil University (2026, 8.1/10) and I'm currently a Java Full Stack Intern at Coremasacia Technologies.

My work leans toward systems that hold up under real load: concurrent backend modules built with Java 21 Virtual Threads, PostgreSQL and MongoDB queries tuned with B-Tree indexing, and container pipelines that keep releases moving without downtime. I also use AI tooling like GitHub Copilot, ChatGPT, and Claude deliberately, as accelerants for debugging and prompt engineering, not shortcuts around understanding the code.

- 🔭 Currently building production APIs with **Java 21**, **Spring Boot 3**, and **React.js** at Coremasacia Technologies
- ⚙️ Focused on microservices architecture, RESTful API design, and distributed data layer optimization
- ☁️ Deploy and manage infrastructure with Docker, Kubernetes, Jenkins, AWS, and Terraform
- 🔐 Build security-first APIs with Spring Security and JWT, backed by JUnit test coverage
- 📜 JetBrains Java Foundations Professional Certificate (2026) — Java concurrency, microservices, RESTful APIs
- 🌱 Currently deepening my knowledge of distributed systems and vector search with Spring AI and Pinecone
